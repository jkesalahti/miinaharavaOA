# miinaharavaOA
A Python implementation of the classic Minesweeper game developed as the final project for the Introduction to Python course at the University of Oulu. Features customizable board dimensions, persistent high-score tracking, and complete game statistics storage.
 
## Overview
 
This project recreates the classic Minesweeper experience while allowing players to customize the game board before starting a new round. The application stores game statistics and high scores between sessions, providing a persistent record of player performance.
 
The purpose of the project is to demonstrate fundamental software development skills in Python, including game logic implementation, user input handling, file operations, and version control.
 
## Features
- Custom board dimensions selected by the player
- Random mine generation
- Automatic revealing of connected empty areas (flood fill)
- Win and loss detection
- Persistent high-score system
- Game statistics stored between sessions
- Graphical user interface
- Input validation for player selections
 
## Technologies Used

- Git
- GitHub
- Course-provided GUI framework
